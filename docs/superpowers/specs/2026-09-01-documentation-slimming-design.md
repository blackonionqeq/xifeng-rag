# README 与 AGENTS 精简设计

日期：2026-09-01

## 目标

缩短仓库入口文档，消除同一事实在多个文件中的重复维护，同时保留隐私、付费语料和索引一致性等不可弱化的约束。本次只调整文档信息架构，不改变程序行为、配置或既有设计决策。

## 职责边界

- `README.md` 是面向使用者的项目首页，只保留项目定位、当前状态、能力概览、安装、最短可运行路径和核心文档导航。
- `AGENTS.md` 是面向编码 Agent 的强制约束清单，只保留工作前路由、语料与隐私边界、架构护栏、关键数据不变量、验证要求和文档职责。
- `docs/design/` 继续作为架构、切块与索引、路线图和技术栈的唯一设计事实来源。
- 新增 `docs/guides/cli-workflows.md`，承接 README 中完整命令矩阵、非主路径操作和各命令的必要说明。

## README 调整

1. 将当前能力按语料、审核、检索、回答和评测合并为少量分组条目。
2. 将“最短流程”收敛为首次运行的 happy path；实验 profile、查询变体和维护命令移入 CLI 指南。
3. 将逐命令实现说明移入 CLI 指南，设计理由保留在既有 design/spec 文档中。
4. 只列四份核心设计文档和少量用户指南，不在首页枚举全部历史 spec。
5. 语料来源只说明外部只读原则和 `corpus.source_dir`，不重复本机绝对路径及完整处理规则。
6. 当前实验规模只保留摘要并链接 roadmap，避免多处维护日期、文章数、块数和题目数。

## AGENTS 调整

1. 将“每次依次读完所有设计文档”改为先读 README，再按任务类型阅读相关设计文档。
2. 删除与 README 重复的项目介绍，以及属于 architecture、roadmap、technology-stack 的流程、实验规模和具体模型配置。
3. 保留并适当合并以下硬约束：外部语料只读、真实正文不得提交、批处理默认本地、完整文章外发例外与二次确认、日志与密钥边界、批准清单和引用来源、增量原子切换。
4. 保留针对增量更新和隐私改动的最低验证要求。
5. 本机课程笔记只作为一条可选参考说明，不得形成运行时或测试依赖。

## 链接与可维护性

- README、AGENTS 和 CLI 指南之间使用相对链接。
- 迁移内容后不复制整段设计；入口文档用一句摘要指向唯一事实来源。
- 对命令名、配置键和文档链接做静态检查，并检查 Markdown 结构与 Git diff。

## 验收标准

- README 能让新使用者快速理解项目并完成最短流程。
- AGENTS 中所有付费语料、隐私、外发和一致性约束仍然明确可执行。
- CLI 指南覆盖从 README 移出的常用命令和特殊工作流。
- README 与 AGENTS 显著缩短，且不再重复维护具体实验数字、模型基线或完整设计说明。
- 文档内部链接有效，修改不触及程序代码或外部语料。

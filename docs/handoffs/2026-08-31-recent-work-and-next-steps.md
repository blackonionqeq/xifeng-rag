## 近期已完成

### 1. V1 检索与回答主链

- 已完成 BM25 + BGE Dense + RRF、可选本地 Reranker、确定性上下文组装、DeepSeek
  结构化回答、原文引用和证据不足协议。
- 已实现显式实验能力：父子分层检索、保守查询改写、证据充分度观测层。
- 当前实验规模仍只有少量已批准文章和 pilot 问题，结果只用于跑通流程和发现失败案例，不能
  当作泛化结论。

### 2. 文章整体概括与独立主题反查

- 整体概括只读取批准后的块级派生元数据，不重复读取或外发全文；草稿可编辑、批准和保留
  历史来源。
- 已把概括目标压缩到约 80–140 字、最多 200 字；可由用户显式触发 DeepSeek 批量精简待审
  草稿，且只发送派生元数据。
- 已实现独立文章级 BM25 + Dense + RRF 索引。索引文本包含标题、整体概括、话题标题和有
  增量信息的去重关键词，不重复塞入块级概括。
- `articles search` 只返回相关文章与匹配话题，不与原有证据块检索混权；后续可在积累真实
  查询后增加软路由/意图识别。
- 当前已有 5 篇整体概括获批，另有《示例文章丑：阅读策略的边界》的一版精简草稿待审。文章级索引是否
  已包含最新批准状态，应在下一次验证前重新执行 `uv run xifeng articles build-index`。

### 3. 文末付费文章目录清洗加固

- 根因已确认：旧清洗器会从后出现的“备用号”等子目录标记处截断，遗漏前面的主目录；模型
  因此可能把目录单独成块，或混入最后一个正文话题。
- 清洗器已升级为 `deterministic-v4-trailing-catalog-backtrack`，组合明确目录语义、链接数量、
  链接行密度和正文是否恢复等信号，并回溯到最早的目录入口。
- 高置信度目录自动移除；冲突信号进入人工清洗审核；普通单链接和短参考列表不会被自动删。
- 新增 `uv run xifeng corpus cleanup-dry-run`，只显示标题、截断位置和计数，不输出正文、URL，
  也不写业务数据。
- 分块 Prompt 增加目录防御，并在调用模型前检查旧规范正文的残留目录；命中时不会调用模型。
- 新清洗版本会停用被取代的未批准中间版本，并能在索引切换后正确恢复当前清洗版本状态。
- 测试覆盖粗体拆词、同行多链接、空锚文本、多账号目录、正文恢复、普通尾部引用、分块前阻断、
  dry-run 隐私和版本状态。

# 第六道文章反查题设计

## 目标

把用户基于真实阅读记忆提出的问题加入本地文章反查评测集，用于观察检索系统能否从“努力学习
可能只是在给组织贴金，真正价值来自开创性贡献”这一组自然回忆线索，找回《示例文章丁，
怎么才能给自己谋个前途？》一文。

## 数据变更

- 在 Git 忽略的 `data/article_discovery_queries.json` 中新增 `article-discovery-006`；
- 原样保留用户问题，避免围绕当前索引字段反向优化措辞；
- 使用文章稳定 ID `sn:c13f447ea5527a765fba18537831ad48`；
- 标记为 `user_real_recall` 和 `confirmed`；
- 不预填检索排名或分数，待实际评测后再记录运行结果。

## 验证

使用现有 `load_article_discovery_dataset` 加载题集，确认 JSON 合法、题目 ID 唯一、新题进入已确认
题目集合，并核对标题与稳定文章 ID。

# 语料管理页原文查看设计

## 目标

在 `corpus manage` 的文章操作栏增加“查看原文”入口，让用户无需离开管理页即可核对当前可用文章版本的完整规范正文。该入口只读，不修改外部语料、数据库或索引。

## 版本选择与数据边界

- 文章存在当前已索引版本时，展示该版本的 `canonical_text`，使原文与当前生效索引保持一致。
- 尚未索引、但存在最新导入版本时，展示最新版本的 `canonical_text`。
- 后端根据文章 ID 解析版本，不接受前端指定文件路径或正文路径。
- 正文从 SQLite 的不可变文章版本读取，不直接暴露或读取任意本地文件。
- 页面不解析 Markdown，不展示外部源文件中的非规范正文内容。

## 交互

操作列增加次要按钮“查看原文”。点击后在当前页打开大尺寸只读弹窗：顶部显示文章标题、短版本 ID 和正文字符数，主体使用原生 `<pre>` 展示规范正文，保留换行并自动折行，长文在弹窗内滚动。

弹窗不包含输入、保存或复制到外部服务等操作；可通过关闭按钮、`Esc` 或点击背景关闭。前端通过 `textContent` 写入正文，不解释正文中的 HTML 或 Markdown，因此不引入 Markdown 渲染依赖，也避免正文成为可执行页面内容。

## 接口与错误处理

管理服务增加沿用现有令牌校验的只读原文接口。接口仅接受文章 ID，返回文章标题、选中的版本 ID、字符数和 `canonical_text`。文章不存在或没有可查看版本时返回可读错误；页面在现有操作状态区展示错误，不打开空弹窗。

## 验证

使用自造短文本验证：已索引文章优先展示生效版本；未索引文章展示最新导入版本；存在新待处理版本时不误展示为生效索引原文；接口继续要求管理令牌；正文中的 HTML 仅作为文本显示；页面不增加第三方或远程资源。

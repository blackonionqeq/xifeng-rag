# 语料管理页只读分块查看设计

## 目标

在 `corpus manage` 的文章操作中增加只读的“查看分块”入口，便于直接核对当前生效的已批准分块和已批准细话题，不进入审核或修改流程。

## 状态与数据边界

- 文章有当前已索引版本时，查看该版本的最新已批准清单。
- 文章尚未建索引、但最新活动版本已批准分块时，查看该已批准清单。
- 其他状态不显示查看按钮。待审分块提案不属于“现有分块”。
- 顶层分块从不可变的 `ApprovedManifest` 读取，包括 `include_in_index: false` 的分段。
- 细话题只读取与该清单绑定的最新已批准 `SubtopicSet`；待审草案、失败记录和已替换记录不展示。

## 交互

操作列显示次要按钮“查看分块”。点击后在当前页打开大尺寸只读弹窗，顶部显示文章标题、版本和分块/细话题数量；主体按清单顺序展示每个分块的标题、原子单元范围、是否进入索引、概括和关键词，以及其下已批准细话题的标题、范围和概括。无细话题时明确显示“暂无已批准细话题”。

弹窗不包含输入框、保存、批准、生成或重建索引操作；可通过关闭按钮、`Esc` 或点击背景关闭。

## 接口与错误处理

管理服务增加带原有令牌校验的只读详情接口。后端根据文章 ID 重新解析当前可查看的版本与清单，不信任前端传入的 manifest 或细话题集 ID。文章不存在或尚无已批准分块时返回可读错误，页面在原有操作状态区显示，不打开空弹窗。

## 验证

使用自造短文本覆盖：无已批准分块时无入口；已批准但尚未建索引时可查看；已索引且有新待审版本时仍查看生效旧版本；`include_in_index: false` 仍展示；无细话题正常展示；只展示已批准细话题；接口继续要求管理令牌；页面不引入远程资源。

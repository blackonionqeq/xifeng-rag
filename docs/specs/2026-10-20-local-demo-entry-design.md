# 本地演示入口设计

状态：已确认并实施 v0.1。

## 1. 目标

新增一个面向面试演示的本地页面，把现有两项核心能力集中在一个入口：

- **找文章**：根据记得的主题、案例或局部概念反查文章；
- **问文章库**：检索原文证据，在明确披露并确认后调用 Generator，展示回答与引用。

第一版强调可理解的完整流程，不承担语料管理、实验调参或 benchmark 控制台职责。

## 2. 命令与边界

使用独立命令启动：

```powershell
uv run xifeng demo
```

服务只监听 `127.0.0.1` 的随机端口，使用进程内随机令牌保护 API。页面静态资源随 Python
包交付，不增加前端框架或构建工具。公开录屏或部署应换用自造短文本语料；第一版只实现本地
演示，不增加登录、多用户、云部署或完整聊天历史。

## 3. 找文章

找文章复用当前默认的 `disagreement_cascade` 和最新分层文章索引，返回：

- 标题、发布时间和已批准 AI 概括；
- 匹配话题、细话题和候选来源；
- 排名、融合分数及本次实际触发的检索层。

这些结果用于文章发现，不作为回答引用，也不自动改变问答检索范围。第一版不实现“基于选中
文章继续提问”的文章范围过滤。

## 4. 问文章库与外发确认

问答使用当前正式基线：BM25 Top-5、确定性上下文组装、`supplement=off` 和生产
`EvidenceBoundGenerator`。交互分为两个请求：

1. `prepare` 在本地检索并组装上下文，返回证据标题、段落范围、短预览、证据块数、原文字符
   数、服务、模型和最多请求次数；
2. 页面展示披露，用户点击“确认并生成”后提交一次性 `prepared_id`；
3. `answer` 原子取走对应准备结果，再创建外部客户端并生成回答；
4. 返回结构化状态、回答段、限制说明、实际请求次数、耗时，以及被引用证据的本地原文。

没有证据时仍生成准备结果，但确认后只在本地返回 `insufficient_evidence`，不读取 API 密钥、
不创建客户端且请求数为零。

## 5. Prepared 状态

准备结果仅保存在进程内存：

- 使用不可预测的随机 ID；
- 默认十分钟过期；
- 确认时先从存储中删除，因此只能使用一次；
- 每次访问都会清理过期项，并限制最多保留 20 项；
- 服务关闭后全部消失，不写入 SQLite 或日志；最近问题清单不属于 prepared 状态；
- 保存的是已经组装好的固定上下文，确认后不重新检索。

同一时刻只允许一个 Generator 请求，避免重复点击造成并发外发。文章反查和本地准备不受该锁
影响。

## 6. 页面结构

页面顶部只提供两个标签：`找文章` 和 `问文章库`。

找文章页包含查询输入、搜索按钮和文章卡片。问文章库页包含问题输入、本地检索按钮、外发披露
卡片、确认按钮，以及回答、限制说明和可展开引用。默认界面不展示 Build、候选深度、RRF、
Reranker 等实验参数。

两个标签页分别显示紧凑流程图，并随操作高亮当前步骤。流程图用颜色区分本地处理、用户确认
和外部生成；文章反查明确标注只返回候选文章，不执行针对本次查询的实时生成。

## 7. 隐私与持久化

- 页面和 API 只在本机回环地址开放；
- 反查只展示已批准的模型概括和安全元数据；
- prepare 只向本地浏览器返回证据短预览，不调用网络；
- 只有明确确认才向配置的 Generator 发送准备阶段列出的证据；
- 完整证据只在生成完成后作为本地引用详情返回；
- 普通服务器日志不记录请求体、问题、证据正文、Prompt、Provider 原始响应或 API 密钥；
- 第一版只在 Git 忽略的 `data/demo-question-history.json` 保存最近 50 个问答问题及最近使用
  时间，用于挑选现场演示题；不保存回答、证据、引用、Prompt 或 Provider 响应。相同问题去重，
  页面支持重新填入、单条删除和全部清空。

## 8. 验收

自动测试使用自造短文本与假的搜索器和 Generator，覆盖：

- 找文章返回安全展示字段；
- prepare 不创建 Generator；
- 披露数据与固定上下文一致；
- prepared ID 一次性使用并会过期；
- 无证据路径零外部请求；
- 有证据时返回结构化回答和可定位引用；
- API 令牌校验、请求体限制、静态资源和关闭接口；
- 应用状态不写入数据库或普通日志。

## 9. 非目标

- 用 AI 概括替代可引用原文；
- 多轮对话或会话记忆；
- 自动把反查结果加入问答权重；
- benchmark 运行与结果管理页面；
- 检索参数控制面板；
- 公网部署、登录或多用户隔离；
- 跨文章专项回答机制。

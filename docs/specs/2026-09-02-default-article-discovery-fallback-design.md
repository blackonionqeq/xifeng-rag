# 默认文章反查降级策略设计

状态：已确认，2026-09-02。

## 目标

将 `xifeng articles search` 的默认行为从累计文章文档上的 BM25 + Dense + RRF，改为已经完成
离线评测的分层 `disagreement_cascade`。没有批准细话题的文章仍可由概括、关键词和原文层召回；
旧累计检索保留为显式兼容策略。

当前 6 道用户真实反查题上，`disagreement_cascade` 的 Hit@1/3/5 与 MRR 均为 1.0。这个小样本
只支持将其作为当前默认候选，不构成泛化结论；后续仍需扩大 dev 和 holdout。

## 默认数据流

默认搜索读取最新分层索引套件，并按以下顺序执行：

1. 概括层分别运行 BM25 和 Dense，文章聚合使用 `best_unit`；
2. 若两路 Top1 不一致，直接追加细话题层 BM25 和 Dense；
3. 若两路 Top1 一致但清晰度不足，追加关键词层 BM25 和 Dense；
4. 新层仍不清晰时按既有 `disagreement_cascade` 规则继续到细话题或原文层；
5. 所有已触发通道的文章排名以固定 RRF 融合，旧层强候选不会被新层直接覆盖。

清晰度继续使用三个层内可观测信号：BM25/Dense Top1 一致、Top1 相对 Top2 分差，以及两路
Top-K Jaccard 重合率。默认阈值沿用离线模拟值：相对分差 `0.1`、重合率 `0.5`、融合
`rrf_k=60`。

## CLI 与结果

- `xifeng articles search` 新增 `--strategy`，默认 `disagreement_cascade`；
- `--strategy cumulative_hybrid` 显式运行原有累计文档检索，`--mode` 只控制该兼容策略；
- 默认结果继续返回标题、发布时间、概括、匹配话题和匹配细话题；
- 结构化与文本输出增加实际触发层和 `disagreement_cascade` 来源标识；
- 分层套件缺失、Build 不可用、各层快照不一致或 Embedding Profile 不匹配时明确失败并提示
  运行 `xifeng articles build-layered-index`，不得静默切回旧策略。

## 实现边界

线上控制器复用分层搜索与文章文档读取，不依赖评测数据集或已保存的评测结果。评测模块和线上
控制器共享纯确定性的清晰度判断与排名融合函数，避免两套同名策略产生行为漂移。全部检索仍在
本地进行；文章发现结果不是原文证据，也不进入 `search`/`ask` 的引用链。

“细话题优先”保留为下一轮实验：先验证如何识别目标文章缺少细话题以及如何避免概括层融合
破坏细话题强命中，再决定是否替换默认顺序。

## 验证

- Top1 一致且清晰时只触发概括层；
- 概括双路不一致时优先触发细话题层；
- 缺少细话题时仍能继续原文层并返回文章；
- 逐层结果按与离线模拟相同的 RRF 规则融合；
- 旧 `cumulative_hybrid` 策略保持原排名与参数行为；
- 缺失、失效或跨快照的分层套件明确报错；
- CLI 默认值、文本输出和 JSON 输出覆盖新策略元数据。

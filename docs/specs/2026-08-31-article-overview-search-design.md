# 文章概括与文章级搜索设计

状态：已确认，2026-08-31。

## 目标

支持用户只记得模糊主题时反查相关文章，并在打开原文前快速回顾该文还讨论了什么。文章级
搜索返回文章列表；现有话题块检索继续负责定位具体证据。

## 数据边界

- `published_at` 表示微信原始发布时间，优先从同名 HTML 的 `ori_create_time` 读取，并以
  `create_time` 交叉核对；`captured_at` 继续表示本地抓取时间。HTML 只提供元数据，不作为
  第二份正文索引，外部语料目录保持只读。
- 文章整体概括使用独立、可审核的 `ArticleOverview`，绑定文章版本并记录生成来源，不修改
  已批准且不可变的分块清单。
- 尚无批准分块清单的新文章在同一次分块调用中根据完整规范正文生成概括；已批准文章的兼容
  补生成流程仍只读取标题和完整分块元数据，包括 `include_in_index=false` 的话题。后者不得只
  读取 `TopicChunk`，否则会遗漏未进入检索索引的导言或附录。
- `article_summary` 是 AI 辅助概括，不是作者原话，不能作为回答引用。

## 数据模型

`articles` 增加可空的 `published_at`。新增 `article_overviews`：

```text
id
version_id
proposal_id / manifest_id（至少一个存在）
article_summary
status: pending_review | approved | superseded
provider_id / model_id / prompt_version
created_at / approved_at
```

同一文章版本可以保留多份草稿，但文章级索引只使用最新批准概括。正文产生新版本后，旧概括
不自动复用。

## 生成与审核

尚无批准清单的新文章由分块提案同次返回文章整体概括，并在同一审核页编辑、共同批准；概括
直接根据本次完整原文独立归纳，不根据块级概括机械拼接。对当前已有提案和批准文章，默认仍
使用本地模型根据分块元数据补生成草稿，不重新发送或读取完整正文。概括以文章列表快速扫读
为目标，优选 80 至 140 字、最长不超过 200 字、最多 2 至 3 句，保留核心判断、论证路径和
重要延伸主题，避免套话与重复结论。

用户也可显式触发外部模型批量精简待审概括。该操作只发送标题和完整分块元数据，不发送规范
正文，因此一次命令只做一次批次级隐私披露，不要求逐篇二次确认。替换结果保留新的 provider、
model 与 Prompt 版本，旧待审草稿标记为 `superseded`；已批准概括不可被批量改写。新结果仍是
待审草稿，不自动取得人工批准状态。

## 文章级检索

每篇活动文章构造一份文章级检索文档：

```text
标题 + 已批准文章概括 + 全部批准话题标题 + 去重后的补充关键词
```

块级概括不重复写入文章级检索文档，因为整体概括已经综合这些信息；全部话题标题用于保留
整体概括可能省略的次要主题。关键词汇总后去重，已经出现在标题、整体概括或话题标题中的词
不再重复加入，只补充简称、近义表达和便于反查的概念。

首版使用独立的本地 BM25 与 Dense 索引并以 RRF 融合，输出文章 ID、版本、标题、发布时间、
文章概括、匹配话题和分数。文章级索引与块级索引使用不同数据库 Build 记录、Profile、产物
目录和命令入口，避免改变现有检索基线。没有已批准概括的文章不进入正式文章级索引。

文章搜索只负责发现与回顾，不进入现有 `search` / `ask` 的最终权重。用户可以从文章结果选择
范围，再下钻现有块级原文检索。后续积累真实查询后，可增加 `article_discovery`、
`evidence_lookup` 与 `both` 三类查询意图路由；低置信度时两路都查。即使以后做软协同，也应
融合两路产生的原文块候选，而不是直接相加文章分数与块分数。

## 回填顺序

1. 扫描全部外部文章并补齐 `published_at`。
2. 新的未分块文章在一次全文调用中生成分块与概括，并在同一页面共同审核批准。
3. 给已有已批准文章生成独立待审概括；批准后进入文章级索引。
4. 在语料管理页增加主题搜索，默认返回相关文章列表，并可下钻现有话题块目录。

## 验证

- 发布时间解析覆盖 epoch、可读时间回退、字段冲突和无 HTML 场景。
- 新联合提案的概括输入是完整规范正文；既有文章的兼容补生成输入不含 `original_text`，且包含
  不进入索引的话题。
- 未批准概括不能进入文章级索引；新正文版本不能复用旧概括。
- 文章级搜索只返回文章记录，引用与问答仍使用规范正文的 `original_text`。

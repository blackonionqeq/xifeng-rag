# 分层文章反查与降级策略实验实施计划

对应设计：[`docs/specs/2026-09-02-layered-article-discovery-evaluation-design.md`](../specs/2026-09-02-layered-article-discovery-evaluation-design.md)

1. 建立四种隔离层的检索单元模型与确定性选择逻辑：概括、关键词、已批准细话题和已批准原文子块。
2. 为每层构建独立、不可变且默认不激活的 BM25 + Dense Index Profile 与 Build，保存安全单元清单、元数据和可重建索引。
3. 实现单层 BM25/Dense 检索，以及多单元层的 `best_unit` 和 `top_n_rank_fusion` 文章聚合，记录稳定范围、原始排名、分数与文章单元数。
4. 扩展文章反查评测，运行至少八个隔离基础通道，保存逐题排名、层内间隔、一致性、延迟、快照、模型、参数和 Git 状态，不持久化正文或生成元数据全文。
5. 实现只读取评测结果的离线降级模拟，校验题集、语料快照、Profile、候选深度、聚合方法与 RRF 参数，并报告准确性、触发比例、延迟估算和逐题变化。
6. 增加薄 CLI 入口和使用文档；保留现有累计拼接索引与评测命令作为消融对照。
7. 使用自造短文本覆盖四层隔离、无细话题、多单元聚合、长文章入口偏置、原文范围追踪、结果隐私和不兼容运行拒绝；运行 Ruff、Pyright 与完整 pytest。

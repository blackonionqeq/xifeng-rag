# 语义优先分块与语料排除实施计划

## 目标

在不修改外部语料的前提下，以本地配置排除一篇已确认不完整的文章，并让本地模型按
自然语义而非固定块数或字符阈值提出话题分块。

## 实施步骤

1. 扩展 `CorpusSettings`，增加默认空的 `excluded_article_ids`，校验空值和重复值。
2. 扩展语料扫描摘要；扫描时按稳定文章 ID 跳过排除项、停用已有记录并报告未匹配 ID。
3. 将 CLI 本地配置传给扫描器，并明确输出发现、排除和未匹配数量。
4. 升级分块 Prompt 版本，要求最少必要语义块，移除常见块数和字符阈值警告。
5. 禁止批准 inactive 文章版本的旧提案。
6. 更新示例配置、设计说明和使用文档。
7. 增加配置、扫描、CLI、单块提案和 inactive 审核测试。
8. 运行 pytest、Ruff、Pyright 和构建；扫描真实语料确认 113 篇中排除 1 篇。
9. 对一篇完整短文和一篇长文生成新策略提案，导出审核产物并报告边界质量。

## 完成条件

- 外部语料文件没有变化；
- 已确认不完整文章不会进入待分块集合或索引；
- 完整短文可合法生成单个语义块；
- 提示词和警告不再包含固定块数及字符目标；
- 自动化质量检查全部通过；
- 真实短文和长文提案可供人工审核，失败时保留诊断且不批准。
